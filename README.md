# Pico 防犯ライト（Raspberry Pi Pico 2 W）

人感センサーで人の動きを検知すると、LEDとブザーで知らせる防犯ライトです。
PCにつながなくても、USB電源につなぐだけで動きます。

## 動き
1. 起動して30秒：黄色が点滅（人感センサーの安定待ち）
2. 待機中：緑が点灯
3. 人を検知：赤が点灯し、ブザーが3回鳴る
4. 最後の検知から10秒間：赤のまま（動き続ける間は延長）
5. 消える前の3秒間：黄色
6. 緑に戻って待機

## ハードウェア
- Raspberry Pi Pico 2 W（MicroPython v1.29.0）
- 人感センサー：Panasonic PaPIRs EKMC1601111
- LED：赤・黄・緑（各330Ω）
- 電子ブザー（5V）：NPNトランジスタ 2SC1815 で駆動（ベース抵抗1kΩ）

## ピン割り当て
| 部品 | ピン |
| --- | --- |
| 赤LED | GP15 |
| 黄LED | GP14 |
| 緑LED | GP13 |
| 人感センサー OUT | GP16 |
| ブザー（トランジスタのベース） | GP17 |

## 工夫した点
- **保持時間**：人感センサーは人がいても検知と非検知を細かく繰り返すため、「最後の検知から10秒間は警報中」とみなしてLEDのチカチカを防いだ
- **RP2350-E9の回避**：Pico 2 Wのチップの不具合で、センサーの入力が一度Highになると張り付く問題が起きた。データシートの回避策（入力バッファを読む瞬間だけONにする）をソフトウェアで実装し、外付け部品なしで解決した
- **トランジスタでブザーを駆動**：5Vのブザーは、Picoのピン（3.3V・数mA）では直接鳴らせないため、トランジスタをスイッチにしてUSBの5Vで鳴らしている

## 使い方
1. Picoに MicroPython を書き込む
2. `main.py` をPicoに保存する（電源を入れると自動で動く）
3. USB電源につなぐ
